how does the serverless pipeline work?

It is an event-driven document pipeline. A file lands in Cloud Storage, an OBJECT_FINALIZE notification hits a Pub/Sub topic, a push subscription POSTs to Cloud Run, and the service processes the document, writing structured rows into BigQuery [session:session_03::chunk_003].

The same shape is documented for Cloud Build jobs, which run each build step in its own container [doc:acb62fa7#0000].

Set up your own search key

The hub can fall back to a live web search when its local knowledge base has no answer. You can use the shared public tier with no setup at all, or bring your own Keenable key for higher limits. A key is stored in this browser only and is sent only to api.keenable.ai, never to this site.

No key needed to try it. The public tier allows 1,000 searches per hour per IP. A free key raises the limits and is your own quota.

  1. 1 Open the Keenable console

    Go to app.keenable.ai/console/api-keys and sign in (or create a free account).

  2. 2 Create an API key

    Click Create key and copy the value. Keenable keys start with keen_. Treat it like a password — it bills against your account.

    There is no second identifier. Unlike Google's Custom Search you do not need an engine ID or project setup — one key is the whole configuration.

  3. 3 Paste it into Settings

    Open Settings in this hub, paste the key into Keenable API key, and click Save.

  4. 4 Test it

    With Settings still open, click Test credentials. You should see “✓ Working — Keenable returned N result(s).”

    If it fails, the message names the exact cause and the fix — a rejected key, exhausted credits, or a rate limit. Leave the key field empty and press Test again to check the public tier on its own.

  5. 5 Turn on the fallback

    In the chat panel, tick Allow live-web fallback. The hub will search the web only when its own knowledge base has no answer, and it always labels web-derived answers as unverified with their sources.

    Results from these domains are preferred, because they are the primary sources for this subject:

    cloud.google.com/* developers.google.com/* firebase.google.com/* ai.google.dev/* codelabs.developers.google.com/* google.github.io/* github.com/* adk.dev/* antler.co/*

    These are a preference, not a filter. If nothing on this list matches, the search still returns its best results and the answer is labelled as coming from outside the trusted set — better than showing you nothing.

What leaves your browser

Only your question, truncated to 256 characters and collapsed to a single line, is sent to api.keenable.ai. Your key goes to Keenable and nowhere else — it is never sent to this site's origin and is never logged server-side.

Forget search key in Settings erases it from this browser.

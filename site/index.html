Antigravity 8-Question Review Harness (/grill-me)

Four production review modules derived from Session 03 (Zack Akil) to stress-test architecture before deploying to Google Cloud.

grill-me-deploy-readinessModule 01

Validates Cloud Run service configurations, container packaging size, startup probe readiness, and cold-start latency thresholds under traffic bursts.

grill-me-securityModule 02

Enforces IAM least-privilege scoping, dedicated non-root service accounts, Secret Manager isolation, and ingress network firewall rules.

grill-me-observabilityModule 03

Inspects structured JSON Cloud Logging, OpenTelemetry tracing context propagation, and Cloud Monitoring alert policies for error budgets.

grill-me-architectureModule 04

Evaluates Pub/Sub dead-letter queue (DLQ) topology, Eventarc event schema versioning, and BigQuery streaming sink partition design.

ADK Production Topology Starters

Official starters based on Google's Agent Development Kit (Mauricio Arrechea & Fabian Desnoes, Session 02) with state reconciliation and tool gating.

parallel_agent_starter.pyPattern 3

Topologies: Fan-out • Concurrent • Fan-in
hierarchical_agent_starter.pyPattern 4

Supervisor agent orchestrating specialized sub-agents with A2A protocol point-to-point messaging and centralized token spend caps.

Topologies: Supervisor • Delegation • A2A

Standard Cohort 7-Zone Repository Layout

folder-layout.md →

Standardized project directory convention ensuring clean separation of architecture contracts, agent code, cloud infra, and evaluation test suites.

specs/

Architecture Decision Records (ADRs), interface RFCs, requirements, and system boundary contracts.

design/

System architecture diagrams, data models, interface wireframes, and schema specifications.

src/

Core application source code, ADK multi-agent definitions, runtime handlers, and model clients.

infra/

Terraform modules, IAM policies, and GCP infrastructure declarations for Cloud Run and Pub/Sub.

tests/

Pytest test suites, eval verification harnesses, agent benchmark runs, and synthetic mock fixtures.

deploy/

Container Dockerfiles, Cloud Run configurations, CI/CD pipeline triggers, and operational deploy scripts.

docs/

Operational runbooks, API specifications, developer onboarding guides, and Antler submission dossiers.

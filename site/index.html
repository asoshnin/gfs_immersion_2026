Model Context Protocol Server

Runnable — local + cloud
BYO-key · private plane
Run it yourself — stdio, streamable-http, or SSE

The gfs-mcp server is a runnable Model Context Protocol server: run it on your own machine, or call a deployed instance on the cloud — with your own model + API key (BYO-key). It exposes four tools: three read-only retrieval tools plus a generated advisor. The advisor grounds on the Immersion knowledge base, then answers with your provider key. No key is ever stored server-side, and your key + prompt never touch our origin.

Run locally (developer)stdio · http · sse
# one-line local launch (from the gfs_immersion_hub project root)
pip install -r requirements-mcp.txt                      # one-time: the MCP SDK
python mcp_server.py                                     # stdio (client spawns it)
python mcp_server.py --selftest                          # list the tools

Example MCP client config (Claude Desktop / OpenClaw / compatible client):

{
  "mcpServers": {
    "gfs-mcp": {
      "command": "python",
      "args": ["mcp_server.py"],
      "cwd": "REPLACE_WITH_ABSOLUTE_REPO_PATH"
    }
  }
}

Bring your own key for the advisor (per call, or one env var for local dev):

# No API key needed: the MCP server retrieves, your agent reasons.
export GFS_HUB_URL="https://gfs-immersion.vwoosh.com"   # or your own deployment

Full setup, client configs and tool reference: docs/MCP.md. The server is retrieval-only and runs locally over stdio — no key, no local index, no hosting.
